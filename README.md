# Proyecto de Labora Culturales del CACO

## Descripción
Este proyecto forma parte de las iniciativas de labora culturales del CACO, enfocado en promover y gestionar actividades culturales.

## Características
- Gestión de eventos culturales
- Registro de participantes
- Calendario de actividades
- Documentación de proyectos

## Requisitos
- PHP 7.4+
- Laravel 8+
- Base de datos MySQL

## Instalación
1. Clonar el repositorio
2. Ejecutar `composer install`
3. Configurar `.env`
4. Ejecutar `php artisan migrate`

## Uso
Consultar la documentación del proyecto para más detalles.
